# 예제: 전통시장 × 시군구 인구

질문: 시군구별 인구 10만 명당 전통시장 수는 얼마인가?

| 자료 | 출처 | 받은 방법 | 기준시점 |
|---|---|---|---|
| `data/raw/전국전통시장표준데이터.csv` | 공공데이터포털, 소상공인시장진흥공단 (이용허락범위 제한 없음) | 파일데이터 다운로드 | 2025-11-10 |
| `data/raw/KOSIS_시군구별_총인구_202510.csv` | KOSIS 「행정구역(시군구)별 성별 인구수」(DT_1B040A3) | 통계청 MCP 조회 후 저장 | 2025.10 |

## 이 예제에서 실제로 나오는 함정

| 단계 | 함정 | 그냥 지나가면 |
|---|---|---|
| 1 로딩 | 시장 CSV가 cp949 인코딩 | 읽기 오류 |
| 1 로딩 | 인구 자료 시점 `2025.10`이 숫자로 읽혀 `2025.1` | 10월이 1월로 보임 |
| 1 키 | '중앙시장' 12곳 등 시장명 중복 | 다른 시장을 중복으로 오인해 삭제 |
| 2 코드체계 | 시도명 오탈자 `전북특별차치도` 57행 | 전북 시장 57곳 미매칭 |
| 2 코드체계 | 세종은 주소 둘째 토큰이 읍·면 | 세종 시장 4곳 미매칭 |
| 2 코드체계 | 도로명주소와 지번주소의 시군구가 다른 시장 1곳 | 판정 불가 → 확인 필요 목록 |
| 4 인구 정리 | 시(市)와 그 아래 일반구가 함께 수록 | 인구 9,816,604명 이중 집계 |
| 5 결합 | 시군구명만으로 결합('중구' 등) | 행 1.72배 복제, N:M 7건, 오류 메시지 없음 |
| 6 분포 | 점포수 최댓값 5,111, 개설연도 1780 | 평균 왜곡, 근거 없이 삭제 |
| 분석 | 인구 10만 명당 1위가 부산 중구 | 분모(상주인구) 효과를 결과로 오인 |
