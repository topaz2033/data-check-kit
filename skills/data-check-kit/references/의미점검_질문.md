# 의미 점검 질문 (코드로 판정할 수 없는 것)

답은 자료 설명서·활용가이드·통계설명자료에서 찾고, 찾은 곳을 함께 적는다. 근거가 없으면 "확인 필요".

| 질문 | 답 | 근거(문서·쪽) |
|---|---|---|
| 변수명이 가리키는 개념과 실제 측정이 같은가 (예: '종사자'에 대표자 포함?) | | |
| 0은 실제 0인가, 미응답·해당없음인가 | | |
| 빈칸·특수값(-9, 999 등)의 뜻은 무엇인가 | | |
| 금액 단위는 무엇인가 (원·천원·백만원), 연도마다 같은가 | | |
| 기준시점은 언제인가 (연말·연평균·조사일·등록일) | | |
| 관측단위가 일관적인가 (기업 vs 사업체, 본점 vs 사업장) | | |
| 지역코드는 어느 체계인가 (행정표준코드·통계청 코드·법정동), 기준 연도는 | | |
| 산업분류는 몇 차인가 | | |
| 자료가 모집단 전수인가, 표본인가, 등록 자료인가 | | |
| 갱신 과정에서 빠지거나 새로 들어온 관측치가 있는가 (폐업·폐지 반영 방식) | | |
| 이용조건(라이선스·출처 표기)은 무엇인가 | | |
